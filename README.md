# NC加工の引き継ぎ（イワシタ NV2 ＋ SOLIDWORKS CAM）

学校の NCフライス **イワシタ NV2（ファナック 0i-MF Model B）** で部品を削るための知見をまとめたリポジトリです。
機械の操作・安全手順と、SOLIDWORKS CAM でプログラムを作る方法の両方を扱います。

NV2 は共用の機械なので、特定の班や部品に限らず、この機械を使う人なら誰でも読めるようにしています。

## ⚠️ 最初に知っておくべき安全上の注意

1. **作業前に、機械のパラメータが [`docs/machine/parameters.md`](./docs/machine/parameters.md) の表どおりか確認する。** パラメータは変更しても履歴が残らず、誰かが元に戻していることがある
2. **初めて流すプログラムは、シングルブロック＋送り速度オーバーライド0で、1ブロックずつ確認しながら動かす。** 手順は [`docs/machine/operation.md`](./docs/machine/operation.md)
3. **ドライラン中は、送り速度オーバーライドを0にしても軸が止まらない。** ジョグ送り速度のダイヤルを0にしてから始める
4. **SOLIDWORKS CAM でポスト処理したら、NCコードを開いて `G54`〜`G59` が出ているかを必ず目で見る。** 出ていないと、まったく違う場所を削る
5. **工具は、他の人が使っていない番号に登録する。** 共用機なので、番号が重なると他の人の補正値で削ってしまう。0番台・10番台は使われていることが多い

## 🤖 AI に聞きながら使う（おすすめ）

このリポジトリの資料は合わせて1000行以上あり、全部読むのは大変です。
**AI エージェント（Claude、Codex、Antigravity など）にこのリポジトリを読ませれば、日本語で質問するだけで、該当する資料を探して根拠付きで答えてくれます。**

GitHub のアカウントは要りません。リンクを AI に渡すだけで始められます。

### いちばん簡単な始め方（リンクを渡すだけ）

**1. AI エージェントのアプリを用意する**

どれか1つあれば十分です。手元にあるもの、学校で使えるものを使ってください。

| AI | 使うもの | メモ |
|---|---|---|
| Codex | ChatGPT デスクトップアプリの Codex | 無料プランでも、使用上限つきで試せる（2026年11月時点）。お金をかけずに始めるならこれ |
| Claude | [Claude デスクトップアプリ](https://claude.ai/download) の「Code」タブ | 使えるプランは公式サイトで確認する |
| Antigravity | Google Antigravity でフォルダを開く | |

- Windows で使うのに、WSL などの追加の準備は要りません
- 料金や使用上限は変わることがあります。公式サイトで確認し、費用をどうするかは先生や班で事前に相談してください

**2. 空のフォルダを作り、アプリでそのフォルダを開く**

例: `ドキュメント\nc-machining-nv2` という空のフォルダを作って選ぶ。

**3. 次の文をそのままコピーして、AI に送る**

```
https://github.com/ntakao2006-web/nc-machining-nv2 をこのフォルダにクローンして。
クローンしたら AGENTS.md と README.md を読んで、そのルールに従って私の質問に答えて。
```

AI が「コマンドを実行していいですか」「インターネットを使っていいですか」と聞いてきたら、何をするのか確かめてから許可してください（GitHub からリポジトリをコピーするためです）。
「常に許可する」設定にはしないでください。

**4. 新しいチャットを始めて、質問する**

コピーが終わったら、**同じフォルダで新しいチャットを始めてください。** AI がルール（`AGENTS.md`）を自動で読み込んだ状態になります
（会話の途中でコピーしたファイルは、自動では読み込まれないことがあるため）。

```
NV2 で初めて部品を削る。安全のために何から読めばいい？
```

#### 「git がない」と言われたとき

**続けて使う人・記録もしたい人は、Git を入れてください。**

1. https://git-scm.com/ から Git for Windows をダウンロードしてインストールする（インストール画面の選択肢は、基本的にそのままでよい）
2. AI のアプリを一度閉じて、開き直す
3. もう一度、上の 3 の文を送る

**読んで質問するだけなら、Git なしでも使えます**（この方法では記録は残せません）。

1. https://github.com/ntakao2006-web/nc-machining-nv2 をブラウザで開く
2. 緑色の「Code」ボタン →「Download ZIP」を押す
3. ダウンロードした ZIP を展開し、できたフォルダを AI のアプリで開いて、新しいチャットを始める
4. AI に「AGENTS.md と README.md を読んで、そのルールに従って私の質問に答えて」と送る

#### 2回目からは

同じフォルダを開いて新しいチャットを始め、最初に「最新の状態にして」と送ってから質問します（他の人が足した記録を取り込むため）。
ZIP で始めた人は、ZIP をダウンロードし直してください。

### ファナックのマニュアルは NotebookLM で引く

機械のマニュアルは膨大なので、自分で全部読まずに、**NotebookLM（Google の AI ノート）に入れたマニュアルに質問して、辞書のように引いてください。**
マニュアルはメーカーのものなので、このリポジトリには入れていません。**NotebookLM のノートブックは仲間うちだけで共有しています。管理者に共有を頼んでください。**
使い方と質問の例は [`docs/machine/manuals.md`](./docs/machine/manuals.md) にあります。

上の AI エージェントは NotebookLM の中身を読めません。リポジトリに書いていないことを聞くと、「NotebookLM で『〇〇』と聞いてください」と、引くべき質問を教えてくれます。

### チャットだけで使う（アプリを入れられないとき）

Claude や ChatGPT のチャット画面に、このリポジトリのリンクを貼って質問することもできます。
ただし、**リンクを貼るだけでは、全部のファイルを読めるとは限りません。** 答えがあいまいなときは、
「`docs/machine/operation.md` を読んで答えて」のようにファイル名を指定するか、そのファイルの中身を貼ってください。
**機械の操作にかかわる質問は、なるべく上のアプリの方法を使ってください。**

### 記録してほしいとき

「〇〇したら〇〇になった。記録して」と言えば、AI が正しいファイルに書きます。
AI は書いた内容を見せて「記録していいですか」と聞いてくるので、**内容を読んでから OK してください。**
どのファイルに書けばいいかを自分で覚えておく必要はありません。ルールは [`AGENTS.md`](./AGENTS.md) に書いてあり、AI はそれを読んでから動きます。

**読むのは誰でもできますが、GitHub に記録を残せるのは書き込み権限がある人だけです。**

- 続けて記録する人は、GitHub のアカウントを作り（https://github.com/signup ）、このリポジトリの管理者に「書き込み権限（Collaborator）をください」と頼んでください
- 初めて記録を送るときは、ブラウザで GitHub へのサインインを求められます。**パスワードやアクセストークンを AI のチャットに貼らないでください**
- 送れなかったときは、AI が原因（サインイン・ネットワーク・権限など）を調べて、どうすればよいかを教えてくれます

### 困ったとき

| こんなとき | どうする |
|---|---|
| AI が「このコマンドを実行していいですか」と聞いてきた | 何をするのか分からなければ「これは何をするコマンド？」と聞き返す。納得してから許可する |
| 他の人が足した記録が見当たらない | 「最新の状態にして」と送る |
| 何をしているのか分からなくなった | 「今どういう状態？」「最初からやり直したい」と聞く |
| 答えが正しいか不安 | 「根拠はどのファイルのどこ？」と聞いて、その部分を自分でも読む |
| 記録しようとしたら権限がないと言われた | 上の「記録してほしいとき」を見る |

### ⚠️ AI を使うときの注意

- **AI の答えをうのみにしない。** 機械の操作・パラメータ・切削条件・工具の補正値は、根拠を確認し、**実機ではシングルブロック・オーバーライド0で確かめる**
- **機械のパラメータを AI の提案だけで変えない。** 何のために変えるのかを理解してから変え、変えたら必ず記録する
- **現場の手順や担当の先生の指示を、AI の答えやこのリポジトリより優先する。** 食い違ったり分からなかったりしたら、先生に確認する
- **このリポジトリは公開されています。人の名前や個人情報を記録させない。**「〇〇班」「〇〇担当」のように役割名で書く

詳しい説明と用語の意味は [`docs/onboarding/`](./docs/onboarding/README.md) にあります。
