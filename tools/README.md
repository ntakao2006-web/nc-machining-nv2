# ツール

## nccheck.py — NCプログラムのチェックを手伝う

SOLIDWORKS CAM がポスト処理で出したNCコード（ファナック 0i-MF 向け）を読んで、
**人が目で確かめる量を減らす**ための Python スクリプト。2026年度の担当者が自作した。

> **このツールは目視の代わりにはならない。** 何も警告が出なくても、
> [`docs/cam/05-post-and-tool-change.md`](../docs/cam/05-post-and-tool-change.md) の「ポスト処理のたびに確認すること」は自分の目で見る。
> 実機では [`docs/machine/operation.md`](../docs/machine/operation.md) のとおり、シングルブロック・オーバーライド0で確かめる。

### 準備

Python 3 が入っていれば動く（追加で入れるものはない）。NCコードのファイルは読むだけで、書き換えない。

### 使い方

```
python tools/nccheck.py all     プログラム.TXT            工程一覧＋層チェック＋安全チェックをまとめて
python tools/nccheck.py ops     プログラム.TXT            工程一覧だけ
python tools/nccheck.py layers  プログラム.TXT            層チェックだけ
python tools/nccheck.py check   プログラム.TXT            安全チェックだけ
python tools/nccheck.py extract プログラム.TXT --ops 2,3  指定した工程だけを抜き出して表示
```

| 機能 | 何をするか |
|---|---|
| 工程一覧（`ops`） | 工具交換（`M06`）を区切りにして、工程ごとの行の範囲、T・H・D の番号、座標系（`G54`〜`G59`）、Z の範囲を並べる。座標系が無い工程には「★なし」と出る |
| 層チェック（`layers`） | 同じ形を深さを変えて何度も削る工程で、**各層の動きがZ以外まったく同じか**を比べる。全部同じなら、1層分を目で追えば全層を確かめたことになる。違う層があれば、違う行だけを表示する |
| 安全チェック（`check`） | 下の項目を調べて、当てはまれば `[!]` を付けて表示する |
| 抜き出し（`extract`） | 指定した工程だけを取り出す。途中の工程からやり直したいとき用 |

安全チェックで見つけるもの。

- `G54`〜`G59` が1つも出ていない（セットアップのワーク座標系オフセットの設定漏れ。[`docs/cam/02-setup-and-coordinates.md`](../docs/cam/02-setup-and-coordinates.md)）
- 工程に `G43 H○` が無い、`H0` や `D0` になっている
- 最後の `G52`（ローカル座標系）がゼロに戻っていない
- プログラムの終わりが `G91`（増分）のまま
- `G91 G28` の直後に `G90` が無い
- 径補正の開始（`G41`／`G42`）の回数より、キャンセル（`G40`）の回数が少ない

### 注意

- **抜き出したプログラムは、そのままでは流せないことがある。** 末尾の `M30` や、飛ばした工程で指令していた
  座標系・工具長補正・回転数・`G90` が欠けていないかを必ず確かめる
- 層チェックの「不均等」は、最初や最後の層だけ切り込みが違う設定（最終切削量など）でも出る。異常とは限らない
- 退避高さがワークやクランプより上か、回転数・送りが妥当かは、このツールでは分からない
- 手動工具交換のポスト（`iwashita_NV2_posts`）の出力で確かめた。ほかのポストや手書きのプログラムでは、
  工程の区切り方が合わないことがある
