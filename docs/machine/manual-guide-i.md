# MANUAL GUIDE i（対話式のプログラム作成）

形状と切削条件を入力すれば、ツールパスを自動で作ってくれるファナックの機能。長いプログラムを手で打たなくて済む。2026年度は溝加工と平面削りで使った。

## 作成の順序

1. **工具の指定**（工具交換宣言）: プログラムの冒頭で使う工具を指定する。例: 5番のエンドミルなら `T05 D05 M06;`
   - 番号は例。**共用機なので、他の人が使っていない番号を選ぶ。** 0番台・10番台は使われていることが多い（[`../cam/05-post-and-tool-change.md`](../cam/05-post-and-tool-change.md) の「工具番号の割り当て」）
2. **加工条件の指定**: ソフトキーのサイクルから切削の種類を選び、条件を入力する
3. **形状データの入力**: 溝・平面などの形状を入力する

この順序を守らないと入力が進められず、指定が不十分なままシミュレートするとエラーになる。

## 工具データの登録

- 工具長補正: Z原点を工具先端（Z=0）にする運用なら、工具長はすべて `0` でよい。
- 工具径補正: エンドミルの規格上の直径を登録する。**この機械は直径で指定する**（φ12 なら `12.0`。半径の6.0ではない）。
- MANUAL GUIDE i の画面から登録すると迷いにくい（通常のオフセット画面は分かりにくい）。

## 加工条件の決め方

条件表で大枠を出し、**同じ条件で試し削りをして**十分削れることを確かめる。どこまで切り込んでも安全かを肌感覚でつかむことで、工具の破損を防げる。

## シミュレーション

- 「シミュレート」でツールパスを画面で確認できる。早送りで想定外の動きがないか、衝突しないかを事前に見る。
- **画面で確認できても油断しない。** 初回の実行は、送り速度オーバーライド0・シングルブロックで行う。
