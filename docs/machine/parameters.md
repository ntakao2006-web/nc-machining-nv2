# 機械パラメータ（iwashita NV2 / FANUC 0i-MF）

機械側のパラメータは**変更しても履歴が残らない**。誰かが元に戻している可能性があるので、
**作業前に「変更した内容」の表どおりになっているか確認すること。**
触ったらこのファイルに記録する。記録するのは、番号・ビット・略号・変更前後・目的の5点。

## 変更した内容

| 番号 | ビット/略号 | 変更 | 目的・効果 |
|---|---|---|---|
| **1401** | **#4 RF0** | 0 → **1** | 早送り中でも切削送りオーバライドを0%にすれば軸が止まるようにする（試切削・初回確認時の安全確保）。**`0` のままだと、オーバライドを0にしても MDI の早送りが設定速度のまま動いてしまい危険** |
| 14704 | #0 PTO | 0 → 1（2026-09-10） | 「運転中はオフセット入力禁止」の条件を外す。M00停止中に工具長をオフセットへ入れるため。詳細は下の「運転中のオフセット編集」の節 |

RF0=1により、送りオーバライドのダイヤルが早送りにも効く「非常停止の一歩手前の手段」になる。
ただしラピッドオーバライド（F0/25/50/100）とは別系統なので、確認移動を
**シングルブロック＋ラピッドオーバライド最低**で通す運用は引き続き行う。

## No.1401 で気にするビット

この機械の運用で関係するのは次の2つ。ほかのビットの意味は、NotebookLM のマニュアルで「パラメータ 1401 の各ビットの意味を表にして」と聞く（[`manuals.md`](./manuals.md)）。

| ビット | 略号 | この機械での扱い |
|---|---|---|
| #4 | RF0 | **1 にしてある。** 早送り中でも、切削送りオーバライドを0%にすれば軸が止まる |
| #6 | RDR | ドライランを早送り（G00）にも効かせるかどうか。ドライランで確認するときに動き方が変わるので、ドライランの前に今の値を見ておく |

FANUC系でも資料によってビット配置の異なる表記が出回っているため、**ビット番号は機械のパラメータ画面の略号ラベルで必ず確かめる**
（この節の内容は 0i-MF 用のマニュアルで確認したもの）。

## 運転中のオフセット編集（No.14704 #0 PTO）の詳細

ATCが無いこの機械では、M00で止めて工具を交換し**その場で工具長を測ってオフセットに入れる**操作が
毎回発生する。ところが初期設定のままでは「運転中はオフセット編集できません」と出て弾かれる。

**原因は、機械が止まっていてもNC内部では「運転中」扱いのままだから。** FANUCの自動運転ステータスでは
シングルブロック停止もM00停止もどちらも「STOP」で、プログラムは中断しているだけで生きている
（OP信号は点灯のまま）。したがって「M00まで進めれば止まった判定になる」という期待は成立しない。
「RESET」になるのはリセット押下かM30/M02でプログラムが終わったときだけ。

**対処：パラメータ`14704#0（PTO）`を`1`にする。** 値の意味は次のとおり（マニュアル（NotebookLM）で確認、2026-09-17）。

| 値 | 挙動 |
|---|---|
| `0` | 運転中は、工具オフセットの画面から値を入れられない（初期状態） |
| `1` | **運転中でも値を入れられる** |

つまりこれは「停止中だけ許可する」パラメータではなく、**「運転中は禁止」という条件そのものを外す**もの。
隣の`#1（PWO）`が同じ構造でワーク原点オフセット側を制御している。マニュアルでは、ここでいう「運転中」に
自動運転で動いている最中だけでなく、**一時停止している状態やMDI運転中なども含まれる**（マニュアル（NotebookLM）で確認）。
元の制限は軸が動いているかどうかを見ておらず、プログラムが生きているかどうかしか見ていない。

- 実機は`PTO=1`に設定済み（2026-09-10）。NCのメモリをクリアした／バックアップから復元したときは、
  このビットが`0`に戻っていないかを必ず確認する
- **ワーク原点オフセット（`G54`等）を運転中に触る必要が出たら`#1 PWO=1`。** 工具長側とは別ビットなので、
  `PTO`だけ立てても座標系側は弾かれる。現状は未設定
- **「編集が許可される」ことと「入れた値が効く」ことは別。** 軸が動いている最中に書き換えても、
  その時点で既に先読み・解釈済みのブロックには反映されない（切削中に摩耗補正を入れると数ブロック先で
  効きはじめるのと同じ）。したがってパラメータの定義がどちらであっても、下の運用ルールは変わらない
- **オフセット入力は必ずM00停止中に行う。** M00/M01/M02/M30は先読みを止めるので、入れた値が次のブロックから
  確実に効く。**シングルブロック停止中はダメ**で、次ブロックの`G43 H○`が既に先読みバッファに乗っており、
  後から値を書き換えても反映されない（＝刃先が想定より下がる、一番危険な外し方をする）
- パラメータ変更には設定画面の「パラメータ書込み」を1にする必要があるが、これをONにするとアラーム
  `SW0100`が出てサイクルスタートできなくなる（次項）。**パラメータ変更はサイクルスタート前に済ませ、
  「パラメータ書込み」を0に戻してからRESET**する。`14704`の設定自体は保存されるので以後この操作は不要

## アラームSW0100「パラメータ書込み可能です」でプログラムが再開できない

パラメータ変更のため設定画面の「パラメータ書込み」を1にすると出るアラーム。出ている間はサイクルスタートできない。

**このアラームだけを個別に解除する手段は無い。** 解除は「パラメータ書込み」を0に戻してからRESET、の一手のみ
（0に戻した時点で消える機種もあるので、まずRESETせずに0に戻して様子を見る価値はある）。RESETすると
プログラムは先頭に戻る。

したがって**パラメータ変更は必ずサイクルスタート前に済ませる**。加工の途中で必要になった場合は、
先頭からやり直すか、モーダル（`G54`／`G90`／`S`／`M03`／`G43 H○`）をMDIで手で作り直してから
シーケンス番号サーチで再開するしかない。後者は復帰時の位置決めが危険なので、
**ラピッドオーバーライド最低＋シングルブロック**で通し、刃先とワークの隙間を目視しながら入る。
