# NCフライスの操作と安全手順

**初めてこの機械でプログラムを動かす人は、加工を始める前に全部読むこと。**

> **作業前に、[`parameters.md`](./parameters.md) の「変更した内容」の表どおりに
> パラメータが設定されているかを確認すること。** 特に No.1401 #4 RF0 が 0 に戻っていると、
> 送り速度オーバーライドを0にしても早送りが止まらない。

> 操作で分からないことは、ファナックのマニュアルを NotebookLM で引く（[`manuals.md`](./manuals.md)）。

## 使用機械

- 機種: イワシタ NV2（NCフライス盤）
- コントローラー: ファナック 0i-MF Model B
- 主軸回転数の上限: 1800 rpm（小径エンドミルでは、ほぼ上限の1800回転を指定することになる）

## 基本操作（プログラムを動かす前に必ず習得する）

- プログラムを開始するボタン・止めるボタン
- 非常停止ボタン
- プログラムの進行状態をリセットする操作

これらを確実に操作できるようになってから、プログラムを動かす作業に入る。

## プログラム実行前の安全確認手順（毎回守る）

1. Z軸を退避した状態でエアカット（空運転）をする
2. シングルブロック実行にする
3. 送り速度オーバーライドを0にする
4. 1ブロックずつ、各軸の残移動量を確認しながら動かす
   - オーバーライド0で軸が止まった状態で、残移動量を**金尺で実測**して確かめる
   - 問題なければ実行し、おかしければ止める。これを毎ブロック徹底する
   - **工具・ワーク・機械を絶対にぶつけない**ことが最優先

## 座標系の管理

- 座標系には、書き換えると重大な支障が出る値がある。**自分が操作してよい座標系をはっきり区別して、慎重に作業する。**
- プログラムで指定している座標系（G54 など）が、自分が使おうとしている座標系と一致しているかを常に把握する。
- 2026年度のやり方: 工具のゼロ点（Z・XY）を決めるとき、コントローラーに保存されている座標系の位置そのものを書き換え、その座標系をプログラムから呼び出して加工した。
  - 校内の一般学生向けマキノ製NCフライスのような「プリセットして、その場からプログラムを開始する」方式とは違うので注意。

## モード切り替えつまみ

作業中は、今どのモードになっているかを常に確認する。少なくとも次の7種類がある。

1. 原点復帰モード
2. ジョグ送りモード（機械のハンドルを回して送る）
3. ハンドル送りモード（手元のリモコン状のハンドルを回して送る）
4. MDIモード（保存しないプログラムを打ち込みながら操作する）
5. 自動運転モード
6. メモリ編集モード
7. DNC運転モード（**詳細は未調査**）

## プログラムの取り込み（USBメモリ → CNC本体）

- **USBメモリから直接プログラムを起動して加工することはできない。** 必ずCNC本体のメモリに移す。
- ファイルのコピーや移動は、PCのように直感的にはできない。操作の前に毎回ファイル名を手で打ち込んでから操作を選ぶ。
- 拡張子は `.TXT`（大文字）。

**2026年度の運用手順:**

1. USBメモリに、**分かりやすい名前を付けた TXT ファイル**としてプログラムを入れる
2. CNC本体に移す直前に、**本体メモリの空き番号**を確認する
3. ファナックのコントローラー上で、USB内のファイル名をその番号に変える
4. CNC本体のメモリに転送する

プログラム1本で加工するなら、この方法で問題ない。**サブプログラムを使う運用はまだ試していない。**

## ドライラン（ドライカット）の注意

- **ドライラン中は、送り速度オーバーライドを0にしても軸が止まらない。**
  - ドライラン中の送り速度は専用の「ドライラン速度」で決まり、その倍率を決めているのは**ジョグ送り速度のダイヤル**（送り速度オーバーライドではない）。
- ドライランを使うときは、**必ずジョグ送り速度のダイヤルを0にしてから**始める。それでも不意に動く可能性があるので、様子を見ながら進める。
- パラメータ側での対策（ドライラン速度の変更など）は不都合があったため見送り、初期設定のまま運用している。

## マシンロックの注意

- マシンロックは、軸を実際には動かさずに、コントローラー上だけでプログラムの動作を確認できる機能。
- **マシンロックで実行すると、途中停止や終了のあとに座標系がずれる。** これはコントローラーの仕様どおりの動作。
- マシンロックで確認したあとは、**必ず原点復帰（または再起動）をしてから**加工を再開する。2026年度は原点復帰の手順が分からず、再起動で対応した。

## 慣れるためのコツ

- ファナックの操作画面には独特の癖がある。まずは絶対に安全だと確信できる範囲（MDI での軸の少量移動、ファイル操作など）で触って慣れておくと、その後の加工がスムーズになる。
- せっかくNCがあるのだから、汎用フライスの延長として使うのではなく、プログラムを組んで**NCでしかできない精度の加工にNCを使う**こと。
