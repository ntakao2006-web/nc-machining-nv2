# SolidWorks の板部品を基板メーカー向けガーバーにする

NC加工ではないが、SolidWorks まわりの知見としてここに置く。

## SolidWorksの板部品を基板メーカー向けガーバーにする（2026-10-07 実施・動作確認済み）

FR4の板を基板メーカー（JLCPCB等）に「銅なしの機械部品」として作らせるときの手順。
SolidWorks単体ではガーバーを出せないため、**SolidWorks API で形状を取り出し → KiCadの基板ファイルを生成 → kicad-cli でガーバー出力**とする。
GUIでのDXF経由（面をDXF保存 → KiCadで `Edge.Cuts` にインポート）より、穴をドリル穴として正しく扱える点で確実。

- **形状の取り出し**：Python（pywin32）で `SldWorks.Application` に接続し、`OpenDoc6` で読み取り専用で開く
  （元ファイルがGoogleドライブ上なら作業用コピーを開く）。ボディの平面のうち**面積最大の面**を取り、
  その面のエッジを直線・円に分けて座標（単位m）を得る。板厚はボディの境界ボックスから取る
- **pywin32の動的バインディングの癖**：引数なしのメソッド（`GetSurface`、`GetFaces` 等）がプロパティとして
  解決され、`()` を付けると「メンバーが見つかりません」になる。`getattr` の結果がメソッドのときだけ呼ぶヘルパーで吸収する
- **KiCadファイルの生成**：外形の直線は `Edge.Cuts` の `gr_line`、閉じた円（穴）は **めっきなし穴（`np_thru_hole`）のフットプリント**にする。
  `Edge.Cuts` 上の円のままだとルーター加工の扱いになり、位置公差が±0.2mmに落ちる。
  KiCadはY軸が下向きなので、座標はY反転して置く（表裏の区別がない板なら鏡像でも実害はない）
- **出力**：`kicad-cli pcb drc`（外形が閉じているかの確認）→ `pcb export gerbers` → `pcb export drill`（Excellon・mm）→ zip化。
  銅層は空のまま出力してよく、注文時の備考に「No copper. Mechanical part」と書く
- **JLCPCBでの精度**（2026-10時点の公開値）：ドリル穴は位置±0.075mm・穴径±0.08mm程度。φ6.3mm以上の穴と外形はルーター加工で外形公差±0.2mm。
  外形の内角はルーター刃の半径（約R0.5）が残る
