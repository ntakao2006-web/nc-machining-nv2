# CAM のタブ（アドイン）が、起動するたびに消える

## 結論

**アドインの画面で左右両方にチェックを入れ、SolidWorks を正常に終了する。** これで次回からも残る。

アドインの画面（ツールのメニューから開く）には、アドインごとにチェック欄が2つある。

| チェック欄 | 意味 |
|---|---|
| 左側 | 今すぐ有効にする。**その回かぎり** |
| 右側（起動時に読み込む） | 次回の起動からも有効にする |

## 原因

有効・無効の設定は Windows のレジストリに入っていて、**SolidWorks が正常に終了したときに書き込まれる。**
そのため、次のどちらかだと設定が残らない。

- 左側だけにチェックを入れた
- 右側にもチェックを入れたが、そのあと **SolidWorks が異常終了（クラッシュ）した**

2026-08-30 に「CAM のタブがまた消えた」ことがあり、調べると前日に SolidWorks がクラッシュしていた。

## 確かめ方

設定の場所は次のとおり（SOLIDWORKS CAM 2026 の場合。`{...}` はアドインごとに決まった番号）。

```
HKCU\Software\SolidWorks\AddInsStartup\{CCAC6208-0E19-6455-2022-2026CEB541FA}
```

PowerShell で今の値を見る（読むだけで、何も書き換えない）。値が 1 なら「起動時に読み込む」になっている。

```powershell
Get-ItemProperty 'HKCU:\Software\SolidWorks\AddInsStartup\{CCAC6208-0E19-6455-2022-2026CEB541FA}'
```

クラッシュしたかどうかは、Windows のイベント ビューアーの「アプリケーション」のログで、`SLDWORKS.exe` のエラーを探す。

## 何度も繰り返すとき

クラッシュ自体が何度も起きるなら、アドインではなくクラッシュの原因を先に調べる。
SolidWorks 付属の診断ツール（SOLIDWORKS Rx）で、グラフィックスドライバーが認定されたバージョンかを確かめる。
