# SOLIDWORKS CAM の基本：TechDB とデータの保存先

**SOLIDWORKS CAM を初めて使う人は、まずこのファイルから読むこと。**

## 最初に理解すべきこと：TechDBが加工設定の母体である

SOLIDWORKS CAMは「モデル形状」と「TechDB（テクノロジー データベース）に登録されたルール」を
突き合わせて、加工工程を**自動生成する**仕組みになっている。TechDBは単なる工具リストではなく、
**加工ノウハウそのものを溜める母体**であり、ここを理解しないとSOLIDWORKS CAMは使いこなせない。
（この構造に気づくまでに時間がかかりやすいので、最初に読むこと）

### 工程が生成されるまでの流れ

1. モデルから加工フィーチャーを認識する（自動認識／対話式で指定）
2. そのフィーチャーに対して、**TechDBの「ストラテジー」**を参照し、どのオペレーションを
   どの順で当てるかが決まる
3. 各オペレーションに使う工具が、**TechDBの工具ライブラリ／ツールクリブ**から選ばれる
4. 送り速度・主軸回転数が、**TechDBの加工条件表（材質×工具の組み合わせ）**から決まる
5. 上記の結果としてツールパスが計算される

つまり、生成された工程が気に入らないとき、直す場所は2つある。

- **パーツ内で直す** … その部品限りの修正。次の部品には引き継がれない
- **TechDBを直す** … 以後の生成すべてに効く恒久的な修正

初心者が陥る罠は、**毎回パーツ内だけを直し続けて、同じ修正を永遠に繰り返すこと**。
「次の部品でも必ずそうしたい」修正だと気づいた時点で、TechDB側に反映すること。

### TechDBに入っているもの

- マシン定義（使用する工作機械）とポストプロセッサの割り当て
- 工具ライブラリ（実際に保有する工具の寸法・材質・ホルダ）
- ツールクリブ（その機械に載せる常用工具のセット）
- 加工条件（材質ごとの送り・回転数。**パーツに材質が設定されていないと的外れな条件になる**）
- ストラテジー（フィーチャーの種類ごとに、どう削るかの既定手順）
- オペレーションの既定パラメータ

### 運用上の重要な性質

- **出荷時のTechDBはあくまでサンプル。**自社の工具・機械に合わせて育てていくもので、
  育てないと毎回パーツ内で手直しする羽目になる
- **実体は`TechDB.cwdb`という1ファイル。**だからバックアップも移行もファイルコピーで完結する
- **履歴が残らない**（上書き更新）。Gitのように前の状態へ戻せないので、
  まとまった変更を入れた日は必ず日付付きでバックアップを取ること
- TechDBの変更は**新規生成分から反映**され、既存パーツの生成済みオペレーションは変わらない

## CAMデータはどこに保存されるか（3か所に分かれる）

| 対象 | 保存先 | 保存操作 |
|---|---|---|
| 工程・セットアップ・加工原点・座標系 | パーツ/アセンブリファイル内（SLDPRT/SLDASM） | 通常の `Ctrl+S` |
| 計算済みツールパス | 同上（オプション設定次第） | SOLIDWORKS CAMのオプション「一般」で保存ONにする |
| 工具・加工条件・マシン・ポスト・ストラテジー | TechDB（下記パス） | TechDBエディタで編集／ファイルコピーで持ち運び |
| NCコード・セットアップシート | 独立ファイル（任意の場所） | ポスト処理で都度出力 |

**要点**：CAMツリーの中身はパーツファイルに埋め込まれるので、専用の保存コマンドは不要。
一方、工具や加工条件はパーツには入らず、TechDBという別のデータベースにある。
そのため**パーツファイルだけ他人に渡しても、工具・条件の作り込みは渡らない**。

ツールパスだけが開くたびに消えている場合は、オプションでツールパスの保存がOFFになっている
（工程定義自体は残るので、再生成すれば復帰する）。

## 工具プロファイル・加工設定をどう管理するか

**原則：「次の部品でも必ずそうしたい」設定はTechDBへ、「この部品だけ」の設定はパーツ内へ。**

### 工具（刃物プロファイル）
- 正しい置き場は**TechDBの工具ライブラリ**。実際に持っている工具（径・刃長・首下・コーナR・刃数・
  材質・ホルダ）を登録しておく
- 常用する工具は**ツールクリブ**にまとめ、マシンダイアログで「デフォルトとして保存」しておくと、
  以後のパーツで自動的に同じ工具セットが入る
- パーツ内のオペレーション側で工具寸法を直接書き換えることもできるが、**その変更はそのパーツ限り**。
  次の部品には引き継がれず、実物の工具と食い違う原因になるので常用しない

### オペレーションの既定パラメータ（クリーンアップパスOFF等）
- 毎回パーツ内でチェックを外す運用は外し忘れによる二重加工の温床になる。恒久的にそうしたい設定は
  TechDB側の既定値を変更する
- **TechDBを変更しても、既存パーツの生成済みオペレーションは変わらない**（新規生成分から反映）。
  過去の加工プログラムが勝手に変わる心配はない一方、直したいなら既存パーツ側も個別に直す必要がある

### 再現性の担保
- 実際に加工したときのセットアップシートを出力してリポジトリに置いておくと、
  「どの工具・どの条件で削ったか」のスナップショットになる（TechDBは上書きで履歴が残らないため）

## TechDB・ポストのバックアップ

実データの場所（SOLIDWORKS CAM 2026）:

```
C:\ProgramData\SOLIDWORKS\SOLIDWORKS CAM 2026\TechDB\TechDB.cwdb   ← 工具・加工条件・ストラテジー
C:\ProgramData\SOLIDWORKS\SOLIDWORKS CAM 2026\Posts\               ← ポストプロセッサ（Mill\iwashita_NV2_posts.ctl/.lng）
```

これらは常時ディスクに保存されているので日常作業で意識する必要はないが、
**PC故障・OS再インストール・別PCへの移行では失われる**。SolidWorksの「設定ウィザード」が作る
`.sldreg` にはCAM関連は一切含まれないので、別途フォルダごとコピーして退避する。

```powershell
Copy-Item "C:\ProgramData\SOLIDWORKS\SOLIDWORKS CAM 2026\TechDB","C:\ProgramData\SOLIDWORKS\SOLIDWORKS CAM 2026\Posts" -Destination "C:\Users\<user>\Documents\SW_CAM_backup\$(Get-Date -Format yyyy-MM-dd)" -Recurse -Force
```

- 復元はコピーを逆向きに戻すだけ。ただし**SolidWorksを終了した状態で行う**（TechDBは起動中ロックされる）
- 2026年度に作り込んだポストの実物は [`../../config/`](../../config/README.md) に置いてある。TechDB はメーカーのサンプルデータを含むためリポジトリには置かず、管理者から手渡しでもらう。自分の PC への入れ方もそこに書いた
- 取り直すタイミング：工具ライブラリを整備した日、ポストを編集した日
