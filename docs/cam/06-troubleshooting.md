# トラブルシューティング事例（CAM）

> 実際に踏んだ問題と、その結論だけをここに追加していく。新しい事例は`##`見出しで足す。

## 荒加工だけ指定したのに同じパスを2回なぞる問題

**現象**：ポケット加工（Area Clearance / ポケットアウト）フィーチャーで、
「側面の残し代（A）」「島の残し代（S）」「下部の残し代（V）」を全部0mmにしても、
荒加工の並行/オフセットパスの後に、輪郭に沿ってもう一周なぞるパスが追加され、
実質同じ場所を2回削っているように見える。

**原因**：「残し代（Stock to leave）」と、それとは独立した「仕上げ用の追加パス」系オプションが
別パラメータになっているため。残し代を0にしても、後者がONだと輪郭を1周する追加パスが生成される。
今回確認したケースでは、原因は下記のどちらか（フィーチャーの種類・SOLIDWORKS CAMのバージョンによりUIが異なる）。

1. **ポケット加工フィーチャーの場合**：「荒加工」タブ内の「クリーンアップパス（Clean-up pass）」
   チェックボックスがON。これが独立して壁面に沿った追加パスを生成する。
   → **対処：クリーンアップパスのチェックを外す。**
2. **Rough Mill / 一部フィーチャーの場合**：「Finish Passes」タブがあり、
   「Number of finish passes（仕上げパス数）」が1のまま残っていると、
   「Amount（仕上げ代）」を0にしても輪郭をなぞる仕上げパスが1回分生成される。
   → **対処：仕上げパス数を0にする（またはFinish Passesのチェック自体を外す）。**

**紛らわしくないポイント**：「削り残し加工（作成）」にチェックが入っていても、
「機能」欄が「いいえ」になっていれば、別径ツールでの削り残し除去パスは生成されない
（今回のケースではこれは2重加工の原因ではなかった）。

## チェックリスト（荒加工をワンパスで済ませたいとき）
- [ ] 各種「残し代」が全部0になっているか
- [ ] 「クリーンアップパス」的な独立チェックボックスがONになっていないか
- [ ] 「Finish Passes」タブがある場合、仕上げパス数が0になっているか
- [ ] プレビュー（V）でツールパスを実際に確認し、輪郭を2周していないか目視チェック

## パーツ側の工具クリブがTechDBと食い違う（削除した工具が残り、使用回数まで表示される）

TechDBのツールクリブから工具を削除しても、既存パーツで機械定義を開くと削除したはずの工具が残り、
使用回数まで表示されることがある。

原因は、**機械定義とツールクリブがCAMデータ作成時点でパーツファイル内に複製される**こと。
ダイアログが見せているのはTechDBではなく**そのパーツが抱えているコピー**なので、
TechDB側をいくら直しても既存パーツには伝わらない。使用回数の欄は
「そのパーツ内のオペレーションが何件その工具を参照しているか」を示しており、
参照が残っている工具はクリブから削除できない。

対処（2026-09-17に有効を確認）：**機械定義でいったん別の機械を選び、使用する機械を選び直して保存する**。
これでクリブがTechDBから読み直され、パーツ側の内容がTechDBと一致する。

注意：クリブ編集画面にある**パーツ側のクリブをTechDBへ書き戻す操作**は逆向きに働く。
食い違ったまま実行すると、パーツ内に残っていた古い工具がTechDBへ復活するので使わないこと。
